# Product Overview

Postgres MCP Pro Plus is an advanced PostgreSQL database analysis and optimization suite exposed as an MCP (Model Context Protocol) server. It provides AI-powered database tools for performance analysis, health monitoring, and index optimization.

## Core Capabilities

- **Database Analysis**: Schema inspection, object details, relationship mapping
- **Performance Optimization**: Query execution plan analysis, index recommendations using DTA (Database Tuning Advisor) and LLM methods
- **Health Monitoring**: Multi-dimensional health checks (indexes, connections, vacuum, sequences, replication, buffer cache, constraints)
- **Lock Analysis**: Real-time blocking query detection with resolution recommendations
- **Maintenance Planning**: Vacuum analysis with bloat detection and scheduling recommendations

## Access Modes

- **Unrestricted**: Full SQL execution capabilities (default)
- **Restricted**: Read-only operations with safety controls, SQL injection protection, 30s timeout

## Target Users

Database administrators, developers, and AI assistants needing PostgreSQL insights and optimization recommendations.

## PostgreSQL Compatibility

- Minimum: PostgreSQL 9.6+
- Recommended: PostgreSQL 12+
- Optimal: PostgreSQL 14+ (enhanced lock monitoring)
